DevLens Privacy Policy

Effective date: November 7, 2026

DevLens is an Android app that inspects installed apps and app files (.apk, .aab, .apks, .xapk) for developers and QA. All analysis runs on your device. DevLens has no backend server, no user accounts, no ads and no analytics.

What DevLens reads on your device

  • The list of installed apps and their APK files. DevLens uses the QUERY_ALL_PACKAGES permission to see every installed app, because inspecting installed apps is its core feature. It reads each app's package name, version, label, icon and APK contents (native libraries, manifest, DEX headers) to detect frameworks, SDKs, build settings and 16 KB page size compatibility.
  • Files you choose. When you open a file with the system file picker, DevLens reads that file to analyze it. It does not copy the file and cannot open other files without your choice.

What DevLens stores

  • Scan results of installed apps, so the list opens quickly next time.
  • Up to 20 recently opened files: the file name, a SHA-256 fingerprint of the file and its scan results. The file itself is not stored.
  • One setting: whether rules update automatically.

This data stays in the app's private storage. Scan results and recent files are excluded from Android cloud backup and device-to-device transfer. You can delete the scan results of installed apps with Clear Local Cache in Settings; uninstalling DevLens deletes everything.

Network use

DevLens makes one kind of network request: it downloads updated SDK detection rules (a small database file) from a public GitHub repository, raw.githubusercontent.com/nguynduyanh169/devlens-rules. This happens at most once a day on an unmetered network when automatic updates are on, or when you tap Update. The request contains no information about you, your device or your apps. GitHub may log technical data such as your IP address, as described in the GitHub Privacy Statement.

Links such as the Android developer documentation open in your browser; DevLens itself sends no request for them.

What DevLens does not do

  • It does not collect, transmit, sell or share personal data or the list of your apps.
  • It contains no advertising, analytics or crash-reporting SDKs.
  • It does not require an account.

Children

DevLens is a developer tool and is not directed to children.

Changes

If a future version adds features that change this policy, such as in-app purchases handled by Google Play, this page will be updated before that version is released, and the effective date above will change.
